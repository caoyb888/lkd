# 莱矿-档案管理系统使用说明

> **版本**: v2.0.0
> **适用角色**: 普通员工 / 档案管理员 / 公司领导
> **最后更新**: 2026-07-26
> **本文档基于当前线上系统（React 新 UI + SQL Server）编写，截图均为真实系统画面（浅色「本色」主题）**

## 1. 系统概述

莱矿-档案管理系统是一套面向企业档案管理业务的**前后端分离应用**，采用"**案卷-文件**"两级传统档案管理模式，覆盖档案从编目录入、审批归档、借阅流转到销毁审计的**全生命周期管理**。

目前系统已完成老档案系统（ruoyi-vue）的历史数据迁移：**案卷 2596 卷、卷内文件 10589 件，年度跨度 1957 ~ 2024 年**，全部置为"已正式归档"状态，可直接检索利用。

### 1.1 核心功能模块

| 模块 | 功能说明 | 主要使用角色 |
|---|---|---|
| **数据概览** | Dashboard 统计卡片、年度趋势图、状态分布 | 全体用户 |
| **案卷管理** | 案卷编目、多维检索、Excel 批量导入、PDF 套打 | 全体用户 |
| **文件管理** | 卷内文件明细录入、拖拽排序、分页浏览 | 全体用户 |
| **归档审批** | 待审核队列、待确认队列、审批历史追溯 | 检查人 / 管理员 |
| **借阅管理** | 借阅申请、审批、归还、历史追溯 | 全体用户 |
| **销毁管理** | 销毁申请发起、领导终审、高危操作审计 | 管理员 / 公司领导 |
| **审计日志** | 全链路审批操作审计 | 管理员 / 公司领导 |
| **系统管理** | 用户管理、部门树管理、数据字典配置 | 档案管理员 |

### 1.2 技术架构

| 层次 | 技术选型 |
|---|---|
| 前端 | React 18 + Vite + Tailwind CSS（「灵动智档·岩层 STRATA」主题，支持暗色/浅色切换、列表/卡片视图切换） |
| 后端 | Spring Boot 3.x + MyBatis-Plus + Sa-Token |
| 数据库 | **生产：SQL Server 2022**（年度分区函数 + 分区方案）；开发：MySQL 8.0（RANGE COLUMNS 分区），同一套代码自动适配两种方言 |
| 打印 | OpenHTMLToPDF 生成 PDF（封皮/侧脊/案卷目录/卷内文件目录） |
| 部署 | systemd 常驻 + Nginx（TLS + 反向代理），部署物料见 `deploy/` 目录 |

## 2. 登录与认证

系统采用 **Sa-Token** 鉴权：登录成功后 Token 保存于浏览器本地，后续请求自动携带。Token 有效期 1 天；**后端服务重启后所有 Token 失效，需重新登录**（系统会自动跳转登录页）。

![登录页](screenshots/01-login.png)

### 2.1 初始账号

| 账号 | 初始密码 | 角色 |
|---|---|---|
| `admin` | `Admin@123` | 公司领导（全部权限） |

> ⚠️ 初始密码仅限首次部署使用，请登录后立即通过「个人中心 → 修改密码」变更。

### 2.2 密码规则

- 至少 **6 位**
- 必须同时包含 **大写字母、小写字母、数字、特殊字符**（`$@$!%*#?&`）

### 2.3 角色与权限

| 角色 | 权限范围 |
|---|---|
| **普通员工** | 新建/补录档案草稿、申请借阅、查看本部门借阅历史（草稿仅自己可见） |
| **档案管理员** | 用户/部门/字典管理、借阅审批、归档确认、Excel 导入、销毁申请 |
| **公司领导** | 销毁审批终审、全量审计日志、全部菜单权限 |

## 4. 案卷管理

### 4.1 案卷目录检索

**路径**: `案卷管理 → 案卷目录`

![案卷目录](screenshots/03-volume-list.png)

**筛选条件**：年度、一级类目、二级类目、归档状态、在库状态、关键词（题名/档号/主题词模糊匹配）

**列表/卡片视图切换**：右上角「列表 ↔ 卡片」按钮，选择结果本地记忆。

**列表列**：档号、案卷题名、年度、一级类目、密级（胶囊标签）、保管期限、归档状态、在库状态、操作。

> 迁移档案的档号已统一为**尾段 3 位补零标准格式**（如 `01.8.01.0101.01.003`）。检索时输入旧格式（`...01.03`）请加零后查询。

### 4.2 新建/编辑案卷

**路径**: `案卷目录 → 新建案卷`，或表格行操作列「编辑」

表单分四区：

| 分区 | 字段 | 说明 |
|---|---|---|
| 分类定位 | 全宗号、年度、一/二/三级类目、设备代号 | 下拉数据来自数据字典 |
| 档号预览 | 自动生成的档号 | 选完前置字段后自动计算展示 |
| 案卷描述 | 案卷题名（必填）、编制单位、密级、保管期限、件数、页数 | 密级/保管期限来自字典 |
| 流程信息 | 立卷人、立卷日期、审核人、归档日期 | 日期选择器 |

**底部操作**：
- `保存草稿` → 状态=草稿，仅自己可见、可继续编辑
- `提交审核` → 状态=待审核，立卷人不可再编辑
- `取消` → 返回列表

### 4.3 案卷详情

**路径**: 案卷目录 → 点击行进入详情

![案卷详情](screenshots/04-volume-detail.png)

- **案卷描述**：全宗号、类目、密级、保管期限等均显示**字典中文标签**
- **卷内文件**：按顺序号展示（关联键为唯一档号）
- **审批历史**：审批人、动作（通过/驳回/退回）、意见、时间
- **操作栏**（按角色与状态动态显示）：草稿→编辑/提交审核；已归档→申请借阅/打印/申请销毁（仅管理员）

### 4.4 Excel 批量导入

**路径**: `案卷管理 → Excel 导入`

![Excel导入](screenshots/06-volume-import.png)

三步向导：下载模板 → 上传 `.xlsx`（前后端双重校验）→ 错误行红色标注或确认导入。**任一行出错则全单回滚**，不产生部分成功。

### 4.5 档案打印（PDF 套打）

**路径**: 案卷详情页 → `打印`

- 打印内容分四部分：**封皮、侧脊、案卷目录、卷内文件目录**
- 点击 `下载 PDF` 获取二进制文件流（OpenHTMLToPDF 服务端渲染）
- 服务器需安装文泉驿字体（`fonts-wqy-zenhei`）以正确输出中文

## 6. 归档审批

### 6.1 审批状态机

```
草稿 ──提交审核──▶ 待审核 ──检查人通过──▶ 待确认 ──管理员确认──▶ 已归档
  ▲                  │                       │
  └──检查人驳回──────┘                       └──管理员退回──▶ 回到待审核
已归档 ──管理员申请销毁──▶ 销毁待审批 ──领导批准──▶ 已销毁（从检索中消失）
```

### 6.2 待审核队列（检查人）

**路径**: `归档审批 → 待审核`

![待审核队列](screenshots/07-approve-review.png)

- 展示所有"待审核"案卷；点击「审核」弹出只读详情 + 审批历史
- 审批意见必填；`通过` → 待确认，`驳回` → 退回草稿

### 6.3 待确认队列（管理员）

**路径**: `归档审批 → 待确认`

- `确认归档` 为高危操作，需二次输入 `CONFIRM` 验证；通过后状态=已归档并记录归档日期
- `退回` 需填写原因，状态回退至待审核

### 6.4 审批历史

**路径**: `归档审批 → 审批历史`

![审批历史](screenshots/08-approve-history.png)

按业务类型（归档审核/借阅审批/销毁审批）、审批人、日期范围筛选；点击行展开完整审批意见；销毁类记录带红色警示条。

## 7. 借阅管理

### 7.1 借阅状态机

```
待审批 ──管理员批准──▶ 已借出 ──登记归还──▶ 已归还
   │                    │
   └──管理员驳回──▶ 已驳回 └──超时未还（每日定时任务）──▶ 逾期未还
```

### 7.2 发起借阅申请

**入口**: 案卷详情页 `申请借阅`（仅已归档且有剩余份数的档案可借）

表单：档号/档案名称（只读）、剩余在库份数（只读）、申请份数（≤剩余份数）、借阅期限、借阅原因。

### 7.3 我的借阅

**路径**: `借阅管理 → 我的借阅`

![我的借阅](screenshots/09-borrow-my.png)

状态标签：待审批 / 已借出·剩余 X 天 / 即将到期（≤3 天，暖橙）/ 已逾期 X 天（红色）/ 已驳回 / 已归还。

### 7.4 借阅审批（管理员）

**路径**: `借阅管理 → 借阅审批`

![借阅审批](screenshots/10-borrow-approve.png)

展示申请人（昵称、脱敏手机号、部门）、申请档案、借阅原因；审批意见必填。`批准` 后档案标记借出并扣减在库份数；`驳回` 写审批日志。

### 7.5 借阅历史与归还

**路径**: `借阅管理 → 借阅历史`

![借阅历史](screenshots/11-borrow-history.png)

普通用户仅见本部门历史；管理员可见全量并按部门/日期/状态筛选。管理员对"已借出"记录点击「登记归还」，确认后恢复在库。

## 8. 销毁管理

> 销毁是最高危操作，必须经公司领导终审，批准后档案从所有日常检索/借阅界面消失。

- **发起（管理员）**: 案卷详情页 `申请销毁`，销毁原因必填（≥20 字），可选上传销毁依据 PDF；提交后案卷显示"销毁待审批"标签
- **终审（公司领导）**: `销毁管理 → 销毁审批`，`批准销毁` 需二次输入"批准销毁"文字验证；`驳回` 恢复正常归档状态

## 11. 运维说明

### 11.1 运行环境

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+ | Spring Boot 3.x |
| SQL Server | 2019/2022 | 生产数据库（Linux Docker 部署亦可） |
| MySQL | 8.0+ | 开发数据库 |
| Node.js | 18+ | 前端构建 |
| Maven | 3.8+ | 后端编译 |
| 字体 | fonts-wqy-zenhei | **PDF 打印中文必需** |

### 11.2 生产部署

`deploy/` 目录提供完整物料：SQL Server 建库脚本（`deploy/sql/init.sqlserver.sql`）、systemd 单元、Nginx 配置（TLS + `/api` 反代 + SPA 回退 + 100M 上传）、证书申请、数据库备份轮转脚本、发布脚本，详见 `deploy/README.md`。

### 11.3 年度分区扩容（SQL Server）

每年为下一年度新增分区边界：

```sql
-- 示例：进入 2029 年时执行
ALTER PARTITION SCHEME ps_year NEXT USED [PRIMARY];
ALTER PARTITION FUNCTION pf_year() SPLIT RANGE (N'2029');
```

MySQL 开发库对应语法见 `sql/init.sql` 末尾注释。

### 11.4 定时任务

每日凌晨自动执行：扫描逾期未还借阅 → 状态置为"逾期" → 生成系统内待办通知。

### 11.5 数据库备份

`deploy/backup.sh` 提供 SQL Server 备份 + 轮转（保留最近 N 天），建议 crontab 每日执行。

## 12. 常见问题（FAQ）

**Q1: 登录后侧边栏某些菜单不显示？**
菜单按角色动态过滤。普通员工不显示"系统管理"，"销毁审批"终审仅公司领导可见。

**Q2: 提示"未登录或登录已过期"？**
Token 有效期 1 天，且后端重启后所有 Token 失效。系统会自动跳转登录页，重新登录即可。

**Q3: 用老档号（如 `01.8.01.0101.01.03`）搜不到档案？**
迁移时档号已标准化为尾段 3 位补零（`01.8.01.0101.01.003`），检索请加零后查询。

**Q4: 为什么某些档案在列表中搜不到？**
可能原因：草稿状态（仅立卷人可见）、已被销毁、筛选条件不匹配（点「重置」）。

**Q5: 借阅申请被驳回后能否再次申请？**
可以。驳回记录不影响重新发起申请（只要档案仍有在库份数）。

**Q6: 列表里的"【待整理】占位案卷"是什么？**
历史数据迁移时，部分卷内文件在老系统中找不到所属案卷，系统为其自动生成了占位案卷挂接，保证数据可检索。档案管理员核实后可补登正式案卷信息。

## 13. 附录

### 13.1 档号生成规则

格式：`全宗号.一级类目.二级类目.三级类目.设备代号.案卷号`（案卷号尾段 3 位补零）

示例：`01.8.01.0101.01.003`

### 13.2 错误码速查

| 错误码 | 含义 |
|---|---|
| `2000` | 操作成功 |
| `401`（业务码） | 未登录或登录已过期 |
| `4000-4019` | 参数校验异常 |
| `4020-4050` | 业务逻辑冲突（档号重复、借阅超限等） |
| `5000` | 系统未知异常 |

### 13.3 联系与支持

如遇系统问题，请联系档案管理员，或查阅日志：
- `logs/backend-prod.log` — 后端运行日志
- SQL Server 侧备份文件位于数据库卷 `/var/opt/mssql/data/`
